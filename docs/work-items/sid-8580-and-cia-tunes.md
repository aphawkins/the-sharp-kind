# SID: the 8580 model and CIA-timed tunes

[SharpKind.Emulation] The SID emulator models the 6581 only, and plays PSID
tunes driven by the 50 Hz frame; RSID files and tunes timed by a CIA timer are
refused (`PsidFile`). Neither shipped tune needs them. Only worth doing if a
rendition ships a tune that does.
